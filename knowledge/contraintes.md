# Contraintes du projet

Ces contraintes s'appliquent à tous les agents. Seul l'humain les modifie.

| Sujet | Contrainte |
|-------|-----------|
| Marché | France d'abord, puis Union européenne |
| Modèle | **Produits 100 % numériques** (tableurs, modèles, guides) téléchargés après paiement, sans fournisseur ni stock (décision de l'humain du 2026-11-14). Ancien modèle physique archivé dans `archives/contraintes-maquettes.md` |
| Budget | 0 € tant que rien n'est vendu. Les seules dépenses prévues (nom de domaine, recherche de similitude de marque) se décident une à une avec l'humain |
| Acquisition client | Contenu organique : TikTok, Instagram, Pinterest, YouTube Shorts |
| Contenu | Sans montrer le visage : démonstrations produit, mains, textes à l'écran, voix off possible |
| Ressources pour filmer | **Aucune** : pas d'animal, pas de sport ou loisir pratiqué, personne de l'entourage pour filmer. Le contenu doit pouvoir se tourner **seul, chez soi, avec le produit uniquement** (bureau, chambre, cuisine, salle de bain) |
| Approvisionnement | Aucun : chaque produit est construit par un script dans `produits/sources/` |
| Délai de livraison client | Immédiat : lien de téléchargement après paiement, avec accord exprès du client pour l'accès immédiat (article L221-28, 13° du code de la consommation) |
| Marge | Au moins **70 % du prix de vente** reste après cotisations (21,2 %), frais Stripe et provision : voir `prix-et-marges.md` |
| Qualité produit | 0 erreur de formule, testé dans Excel, Google Sheets et LibreOffice (fiches O07, O11) |
| Avis | Jamais d'avis inventé ; demande d'avis après achat seulement (fiche C04) |
| Rôle de l'humain | Mandat donné à Claude le 2026-11-14 : gérer le projet de A à Z. L'humain garde ce qui demande son identité ou son argent : immatriculation, compte Stripe, comptes réseaux, toute dépense |
| Temps disponible | Plus de 10 h par semaine, en parallèle des études |
| Plateforme boutique | **Site maison** (Astro) hébergé gratuitement sur Cloudflare + paiement **Stripe** (décision du 2026-11-12) : voir `docs/site-technique.md` |
| Niche | **Tableurs de budget en français**, voir `niche.md` |
| Niches écartées | Maquettes en bois (aucun produit rentable au prix public, 2026-11-14), chat d'appartement, padel, street fishing, journaling ; kits Canva pour commerces gardés en plan B |
