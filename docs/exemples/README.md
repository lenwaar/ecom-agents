Copies figées le 2026-11-13 (synchro n°15, T65) du meilleur livrable existant pour chaque type. Ils montrent la forme, pas le fond : ne recopie jamais leurs chiffres ou leurs faits, vérifie toujours la source actuelle.

Rappel (T64) : un rapport tient en 1 page de résultats et de décisions pour l'humain ; le détail va en annexe, seulement s'il est demandé. Le rapport de veille ci-dessus est un bon modèle de fond, mais plus long que ce qui est attendu désormais : garde sa synthèse (§1), mets les fiches détaillées en annexe.
