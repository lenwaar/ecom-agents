# Test : createur-contenu

## Demande
```
Utilise l'agent createur-contenu : prépare 3 scripts de vidéos TikTok de 20 secondes, sans visage, pour faire connaître la boutique avec les rendus de démonstration (une sur la boîte à musique, une sur la vue éclatée, une « de la planche à l'objet »), plus 5 idées d'épingles Pinterest.
```

## Critères de réussite
- [ ] Livrable dans `outputs/` avec en-tête YAML, statut `à-valider`
- [ ] Chaque script : accroche des 2 premières secondes, plans seconde par seconde, texte à l'écran, voix off facultative, appel à l'action
- [ ] Aucun visage, aucune personne filmée, tout tournable seul à son bureau
- [ ] Mention « Visuel de démonstration » sur chaque vidéo qui montre un rendu
- [ ] Musique de la bibliothèque commerciale de la plateforme seulement
- [ ] Aucun emoji, aucune promesse chiffrée sans source, aucune fausse promotion
- [ ] Aucune publication : l'humain publie
