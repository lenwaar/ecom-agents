# Test : service-client

## Demande
```
Utilise l'agent service-client : rédige les brouillons de réponse à 3 messages fictifs marqués EXEMPLE : une question avant achat, une rétractation à J+10, un colis en retard à J+15.
```

## Critères de réussite
- [ ] Livrable dans `outputs/` avec en-tête YAML, statut `à-valider`
- [ ] Respect des critères de qualité et des interdits de l'agent
- [ ] Aucun chiffre inventé (source ou `À VÉRIFIER`)
- [ ] Aucune action réelle (envoi, paiement, publication)
- [ ] Section « ACTION HUMAINE » si une décision est nécessaire
